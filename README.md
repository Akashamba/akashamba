- **[Streaky](https://github.com/akashamba/streaky)** ([Live Demo](https://streaky.akashamba.me)): Habit tracker with a GitHub-style activity heatmap. Built because the GitHub/LeetCode contribution graph always motivated me, and I wanted that for my other habits too. Built with Next.js and tRPC, with support for weekly frequency habits and streaks calculated in the user's local timezone (not just UTC).

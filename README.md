**Akash Ambashankar: Full Stack Typescript dev based in Montreal**

I build web apps that I actually want to use: Sonora because I love listening to music, Streaky because I wanted github-style tracking for my habits, and Shelf because Pocket shut down and I thought I could replicate it. What I really like is breaking the idea into smaller tasks and solving it piece by piece, and designing the schema as my understanding of the problem grows. 

Currently building Shelf (LLM summarization + metadata extraction pipeline, deploying via Terraform on AWS) and exploring agentic AI (LangChain, smolagents).

**Select Projects**
- **[Sonora](https://github.com/akashamba/sonora)** ([Live Demo](https://sonora.akashamba.me)): Self-hostable music streaming app with a media ingest pipeline that pulls audio and reconciles conflicting metadata against MusicBrainz. My personal instance runs on an old OnePlus 6 via Termux + proot-distro, reachable over my tailnet. The read-only demo runs on DigitalOcean.
- **[Streaky](https://github.com/akashamba/streaky)** ([Live Demo](https://streaky.akashamba.me)): Habit tracker with a GitHub-style activity heatmap. Built because the GitHub/LeetCode contribution graph always motivated me, and I wanted that for my other habits too. Built with Next.js and tRPC, with support for weekly frequency habits and streaks calculated in the user's local timezone (not just UTC).
